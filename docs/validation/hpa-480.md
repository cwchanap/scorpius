# HPA-480 foundation validation

Validation scope: Task 1.2/1.3 foundation and the review-fix rounds, recorded
2026-09-08 on the `hpa-480-ui-visual-parity` worktree. This note covers the
shared canvas, exact-font plumbing, marker ownership, and headless UI picking
seam. Task 3's production battlefield and mesh cutover remain out of scope.

## Headless evidence

The resize proof uses Bevy's real `UiPlugin`, `PickingPlugin`, and
`InteractionPlugin` with the minimum asset/text/input resources they require.
It spawns a real `CanvasRoot` and `Node` stage, lays the stage out through the
UI pipeline, sends a synthetic pointer move through the picking backend at
1920x1080, resizes to 1600x1000, refreshes `UiScale` before the backend, and
verifies that the same authored `GridPos(4, 7)` is recovered from the actual
`HitData.position` and computed stage size in `HoverMap` after the resized
layout settles. The fixture is
`resize_recomputes_scale_before_picking_and_preserves_stage_cell_hits` in
`tests/ui_layout.rs`; it does not start a window, renderer, or `DefaultPlugins`.

The focused camera ownership regression is
`battle_teardown_preserves_unowned_cameras` in `src/app.rs`. It proves that
battle teardown removes the marked `BattleCamera` while preserving an
unowned camera.

## Native foundation proof

required an escalated launch because the sandbox could not discover Metal.
The production game opened at 1280x720 content size: Title typography was
readable, Continue reached Mission 1 Story, Briefing, and Battle, and a
Vanguard cell click updated the selected-unit HUD. Continue read the existing
save; no New Game, purchase, or reward action was exercised.

At commit `9695374`, a temporary native example rendered the production font,
icon, glyph, and board-atlas helpers in a 1280x720 content window titled
`Scorpius — HPA-480 native foundation proof`. CUA visual inspection confirmed
readable bundled typography, four distinct source glyph shapes, recognizable
Move/Attack/Guard/Counter icons, diamond tiles, a complete raised blocker, and
an upright token with its separate shadow. The first proof exposed a blocker
packing overlap; the corrected proof no longer shows the cyan strip beside
the token. Pixel isolation separately verifies the shadow contains no blocker
pixels. The temporary example was removed after building; no capture framework
was added to the application or normal test graph.

This completes the early foundation rendering proof, not full visual parity.
The production battlefield still uses the legacy renderer until Task 3.
Final source comparison, motion, and complete campaign acceptance remain open.
The browser rejected the local reference HTML URL under its security policy;
an allowed source access path or supplied reference captures is still required
for the final source comparison gate.
